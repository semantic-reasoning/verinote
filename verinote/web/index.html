에이전트 설정

로그인된 로컬 CLI 또는 서버 키 파일을 사용하는 OpenRouter API를 선택합니다. 모델 ID는 제공자별로 저장됩니다.

CLI 모델 ID를 비워 두면 해당 CLI 기본값을 사용합니다. OpenRouter를 기본으로 선택할 때는 모델 ID가 필수입니다. 키가 없어도 모델 설정은 저장할 수 있습니다. 키 설정 상태와 CLI 설치 상태는 인증·잔액·모델 접근 권한을 보장하지 않습니다.

OpenRouter 서버 키 파일 준비

서버를 실행하는 컴퓨터에서 verinote --init-config를 실행해 빈 설정 파일을 만드세요. 출력된 파일을 로컬 편집기로 열어 [openrouter]의 api_key를 입력한 뒤 서버를 재시작합니다. 기존 파일은 덮어쓰지 않습니다. 사용자 지정 경로는 verinote --config /absolute/path/config.toml --init-config로 생성하고 같은 경로로 서버를 시작하세요.

POSIX에서는 현재 사용자 소유의 일반 파일과 권한 0600을 요구합니다. macOS 기본 위치는 ~/Library/Application Support/verinote/config.toml, Linux는 $XDG_CONFIG_HOME/verinote/config.toml 또는 ~/.config/verinote/config.toml입니다. 네이티브 Windows에서는 키 파일 권한을 검증할 수 없어 파일 기반 자격 증명을 지원하지 않습니다. POSIX/WSL 환경을 사용하거나 파일 없이 CLI를 사용하세요.

키를 브라우저에 입력하거나 저장하지 않습니다. 키 설정됨은 로컬 설정 여부일 뿐 인증·잔액·모델 접근 확인이 아닙니다. API에는 원문·사전·질문이 전송되며 과금될 수 있습니다. 모델별 max_tokens 한도에 맞는 모델을 선택하세요. 서버 상한 변경은 관리자에게 요청하세요.

제공자가 보고한 CLI/API 토큰을 기록합니다. OpenRouter 보고 비용은 OpenRouter credits이며, 아래 USD 추정과 구분됩니다. 아래 단가를 입력하면 비용을 추정합니다. 보고 비용·크레딧과 별도로 표시하며 구독 할인·기본 쿼터·실제 청구액은 계산하지 않습니다.

CLI 단가의 모델 ID가 비어 있으면 기본 모델 호출에 적용할 가정 단가입니다. OpenRouter 단가는 실행 모델 ID를 명시하세요. 호출에 모델을 지정한 경우 해당 모델 ID와 일치해야 적용됩니다. 단가 변경은 새 호출에만 적용됩니다.
