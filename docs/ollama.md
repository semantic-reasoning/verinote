# Ollama 로컬 제공자

Ollama 서버를 실행하고 사용할 모델을 미리 설치한 뒤 설정에서 **Ollama (로컬 API)**를 선택합니다. 제공자 이름을 클릭하면 로컬 서버에 설치된 모델을 조회합니다. 모델 ID는 필수이며 예: `qwen2.5:7b`입니다. 설정 저장 후 사전 생성·승인 사전 추출·질문에서 선택할 수 있습니다. 저장된 기본 제공자는 자동으로 변경하지 않습니다.

고정 주소는 `http://127.0.0.1:11434`입니다. API 키는 필요하지 않으며 원문·사전·질문은 이 로컬 서버에 전달됩니다. 프록시 환경변수와 HTTP redirect를 사용하지 않고 모델을 자동 다운로드하거나 교체하지 않습니다. Ollama 자체의 모델 설치·실행 환경은 사용자가 관리합니다.

작업 등록 시 모델 tag·설치 digest와 context 32,768·최대 생성 4,096·temperature 0·JSON 형식·keep_alive 5m와 단계별 timeout을 고정합니다. 기본 timeout은 생성 요청 180초, 사전 생성 600초이며 추출은 기존 청크 deadline도 적용합니다. 요청은 대화 context를 재전달하지 않습니다. 입력은 UTF-8 바이트 수로 보수적으로 제한하며 생성 여유와 템플릿용 1,024를 제외한 27,648바이트를 초과하면 거부합니다. 이는 모델의 주의력이나 자연어 의미 품질을 보증하지 않습니다. 전체 요청에는 사전 외에 지시문과 원문도 들어가므로, UTF-8로 3바이트인 문자로 채운 8,000자 추출 청크는 빈 사전으로도 이 예산을 넘으며 이때는 사전을 줄여도 해결되지 않습니다. 거부 상세에 실제 요청 크기와 그 상태에서 가능한 다음 단계를 표시합니다. 문서를 나누어 처리하거나, Ollama가 아닌 다른 제공자의 CLI가 설치되어 있거나 API 키가 구성되어 있고(로그인·모델 접근 권한은 확인하지 않습니다) 요청이 120,000바이트 이내이면 그 제공자로 처음부터 실행할 수 있습니다. 후자는 원문과 사전이 이 로컬 서버가 아니라 해당 제공자에게 전달됩니다. 사전 생성에서는 어느 쪽이든 뒤 구간이나 더 조밀한 부분에서 다시 거부될 수 있으며 그 전 호출 비용은 발생합니다.

`prompt.txt`, `response.json`, `run.json`, `usage.json`을 호출별 데이터 폴더에 보존합니다. provider_call_id·모델 tag·설치 digest·고정 옵션으로 원본을 연결합니다. 입력/출력 토큰은 Ollama가 보고한 값이며 누락은 unknown입니다. 별도 cache·금액은 이 어댑터가 산출하지 않으므로 unknown으로 남기며 0으로 추정하지 않습니다. 로컬 전력·하드웨어 비용도 포함하지 않습니다. 모델 tag가 같은 내용으로 재설치될 수 있으므로 실험에서는 digest도 확인해야 합니다.

서버 미실행·모델 미설치·응답 크기 초과·timeout·잘림·JSON 오류는 실패로 기록합니다. `run.json`과 `usage.json`의 `generate_requested`는 생성 요청(`/api/generate`) 직전에 true가 됩니다. 이 값이 false인 채 실패한 호출(서버 미실행·모델 미설치 등. 모델 목록 `/api/tags` 요청은 생성 요청이 아닙니다)은 사용량에서 시작하지 않은 호출로 표시하고 확인된 호출과 합계에서 뺍니다. usage.json이 없거나 읽을 수 없거나 run.json과 맞지 않으면 확인된 호출로 셉니다. 이 필드가 없는 예전 기록은 확인된 호출로 셉니다. 자동 재시도나 모델 교체는 하지 않습니다. timeout은 원격 생성의 취소를 보증하지 않습니다. 추출은 기존 문서 전체 성공과 사전 확인을 거쳐서만 검토 후보를 게시합니다. OpenRouter의 키·추론 예산 UI와 Claude 전용 병렬 정책은 Ollama에 적용하지 않습니다.

API 형식은 [공식 Ollama API 문서](https://github.com/ollama/ollama/blob/main/docs/api.md)를 따릅니다. 로컬 실측은 별도 Ollama baseline으로 기록하며 Sonnet A/B 수용 결과로 간주하지 않습니다.
